# Research Skill

The `RESEARCH` worker reduces unnecessary implementation work. Search in this order: repository code and documentation, official tools or SDKs, mature open-source projects, reusable components, and reference implementations.

For each serious option, evaluate functional fit, effort, maintenance burden, license, maturity, customization cost, and integration difficulty. Return only the best few options unless broader research is requested. Cite the evidence used and distinguish facts from assumptions.

Finish with an evidence-backed recommendation: **BUILD**, **ADAPT**, or **REUSE**, including why it is the smallest reliable path for the objective.
